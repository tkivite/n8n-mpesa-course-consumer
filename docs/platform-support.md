# Platform Support : macOS, Windows, Linux

This course is designed to be completed on a desktop or laptop running one of these operating systems:

- **macOS**
- **Windows**
- **Linux**

---

## 1. Official support scope

The course officially supports:

- local Docker-based setup
- local n8n development
- local Postman testing
- browser-based workflow editing
- Git-based repo access

All of the above are supported on:

- macOS
- Windows
- Linux

---

## 2. Recommended baseline per platform

### macOS

Recommended:

- recent macOS version
- Docker Desktop
- Terminal / zsh
- Git
- Postman desktop app
- Chrome, Edge, or Safari

Guide : `docs/platform-setup-macos.md`

### Windows

Recommended:

- Windows 11 preferred
- Docker Desktop
- WSL2 backend enabled
- PowerShell or Windows Terminal
- Git for Windows
- Postman desktop app
- Chrome or Edge

Guide : `docs/platform-setup-windows.md`

### Linux

Recommended:

- Ubuntu or Debian-based distro preferred
- Docker Engine
- Docker Compose plugin
- Git
- Postman desktop app or compatible alternative
- Chrome / Chromium / Firefox

Guide : `docs/platform-setup-linux.md`

## 4. What students should expect

### You will be using

- Git
- Docker
- a browser
- Postman
- a text editor or IDE
- environment variables in `.env`

### You will not need

- Java build tools
- Node backend frameworks
- Spring Boot runtime
- Kubernetes

The repo gives you the artifacts already — your job is to run them, understand them, and adapt them.

---

## 5. Best-effort vs fully guided support

### Fully guided in the course

- cloning the repo
- editing `.env`
- running Docker Compose
- opening n8n
- importing workflows
- importing Postman collection
- testing the main STK Push path

### Best-effort support only

These are not the primary focus of the course, so support is lighter:

- corporate VPNs blocking Docker networking
- locked-down office laptops with admin restrictions
- unsupported Linux distros with custom Docker packaging
- aggressive antivirus products interfering with Docker or Git
- advanced proxy setups

If you are in one of those situations, the course still may work, but you may need to adapt steps slightly.
